# {{PROJECT}}

Template for new sourcelocation projects: AGPL-3.0, a Contributor License Agreement, a code of conduct (`404`), a contributing guide and a pull request template.

## After creating a repo from this template

1. Find and replace `{{PROJECT}}` (display name, e.g. `Rondo`) and `{{REPO}}` (GitHub repo name, case as on GitHub) across the repo.
2. Replace this README.
3. Set up CLA enforcement, such as CLA Assistant, and require it in branch protection on `main`.
